## 🚨 COMMON ISSUES & FIXES

| Issue | Fix |
|-------|-----|
| Server won't start | Check port 3001 not in use, clear .next cache |
| Page won't load | Hard refresh (Ctrl+Shift+R), restart server |
| Mobile view wrong | DevTools → device toolbar → select iPhone |
| Arabic text wrong | Toggle language, check direction (RTL/LTR) |
| Form won't submit | Check validation errors, check console |
| Database error | Check auth logged in, check network tab |
| Animations jank | Check Performance tab, look for long tasks |
