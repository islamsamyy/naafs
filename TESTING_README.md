## 📞 TROUBLESHOOTING

### Dev Server Won't Start
```bash
# Check if port is in use
netstat -ano | findstr :3001

# Kill process using port
taskkill /PID [PID_NUMBER] /F

# Start fresh
npm run dev
```

### Page Won't Load
```
1. Check URL: http://localhost:3001
2. Hard refresh: Ctrl+Shift+R
3. Check console for errors: F12 → Console
4. Restart dev server
```

### Form Won't Submit
```
1. Check if form has validation errors
2. Check browser console for JS errors
3. Check Network tab for API errors
4. Verify you're logged in (if required)
```

### Mobile View Not Working
```
1. Open DevTools: F12
2. Click device toolbar (mobile icon)
3. Select iPhone 12 or 375×812
4. Refresh page: Ctrl+R
```

### Can't Find a Feature
```
Use the URL reference:
- Marketing: /, /explore, /freelancers, /auctions
- Auth: /auth/login, /auth/register
- Dashboards: /dashboard/freelancer, /dashboard/client
- Projects: /projects/create, /projects/[id]
- Profile: /freelancers/[id]
```

## 💡 TESTING BEST PRACTICES

### ✅ DO
- [ ] Test in order, don't skip ahead
- [ ] Document issues as you find them
- [ ] Test on actual devices when possible
- [ ] Use different browsers
- [ ] Test edge cases (empty fields, wrong formats)
- [ ] Try both happy and sad paths
- [ ] Check both English and Arabic
- [ ] Test mobile, tablet, and desktop

### ❌ DON'T
- [ ] Skip over failures
- [ ] Assume "if one works, all work"
- [ ] Test only on one browser
- [ ] Test only on one screen size
- [ ] Ignore console errors
- [ ] Test features out of order
- [ ] Forget to document findings
- [ ] Rush through testing
