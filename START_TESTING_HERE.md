## 🚨 IF YOU GET STUCK

**Dev server won't start:**
```bash
# Kill port 3001
taskkill /PID [process_id] /F

# Clear cache
rm -rf .next

# Try again
npm run dev
```

**Page won't load:**
- Hard refresh: Ctrl+Shift+R
- Check console: F12 → Console (any red errors?)
- Restart server

**Need help:**
- See TESTING_README.md (troubleshooting section)
- See TESTING_QUICK_REFERENCE.md (help section)
- Check browser console for detailed error messages
