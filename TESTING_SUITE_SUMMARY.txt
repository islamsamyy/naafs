📞 SUPPORT & TROUBLESHOOTING
================================================================================

Dev Server Won't Start:
  → Check port 3001 not in use
  → Kill process: taskkill /PID [PID] /F
  → Clear cache: rm -rf .next
  → Restart: npm run dev

Page Won't Load:
  → Check URL: http://localhost:3001
  → Hard refresh: Ctrl+Shift+R
  → Check console errors: F12 → Console
  → Restart dev server

Form Won't Submit:
  → Check validation errors
  → Check browser console for JS errors
  → Check Network tab for API errors
  → Verify you're logged in

Mobile View Not Working:
  → Open DevTools: F12
  → Click device toolbar
  → Select iPhone 12 (375×812)
  → Refresh page: Ctrl+R

More Help:
  → See TESTING_README.md Troubleshooting section
  → See TESTING_QUICK_REFERENCE.md Help & Debugging section
  → Check browser console for detailed error messages
