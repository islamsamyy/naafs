# Project Roadmap: Nafis

## Overview
Nafis (نافذ) is a premium, high-tech marketplace for freelancers and businesses in the MENA region. This roadmap outlines the development phases from initialization to production readiness.

---

## Phase 00: Audit & Initial Migration (COMPLETED)
- [x] Initial workspace setup and branding.
- [x] Base layout with RTL/Arabic support.
- [x] Migration of core Stitch design screens.
- [x] Supabase integration (Auth / Database initialization).
- [x] Core Design System (Neon Nocturne dashboard).

## Phase 01: Marketplace Explorer & Talent Feed (CURRENT)
- [ ] Implement the `explore` page for talent discovery.
- [ ] Connect `TalentCard` and `TalentFilters` to Supabase `profiles`.
- [ ] Implement live search and filtering by category/price/experience.
- [ ] Add real-time stats to the discovery feed.
- [ ] Implement "Featured Experts" selection logic.

## Phase 02: Bidding & Project Lifecycle
- [ ] Project details page (`/projects/[id]`).
- [ ] Bidding submission flow for freelancers.
- [ ] Bid management dashboard for business owners.
- [ ] Awarding mechanism and milestone initialization.

## Phase 03: Communication & Feedback
- [ ] Real-time messaging between clients and freelancers.
- [ ] Notifications system (Inbox/Real-time).
- [ ] Reviews and ratings system (Backend + UI).

## Phase 04: Payments & Final Polish
- [ ] Wallet management and transaction history.
- [ ] Security audit & RLS refinement.
- [ ] Performance optimization (Next.js Image / Skeleton loaders).
- [ ] Final visual audit and "Magic" animations.
